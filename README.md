# AI비서 첫걸음 피클 — 가상 강의 랜딩페이지

AI강사 이정임 님의 온라인 특강 **「AI비서 첫걸음 피클」** 소개용 랜딩페이지입니다.
크몽 전자책 《AI 에이전트가 어디까지 할 수 있나? — 피클 첫걸음》(54쪽, 38가지)을 바탕으로
4주 커리큘럼과 강사 소개를 구성했습니다.

- 강의 일정: 매주 목요일 20:30 ~ 21:30 (Zoom Live, 4주)
- 이 페이지는 **가상 시연용**입니다. 실제 결제·모집·연락은 이루어지지 않습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 탭 4종, 신청 박스, 신청 모달) |
| `styles.css` | 디자인·반응형 (PC 2단 / 모바일 1단 + 하단 고정 신청 바) |
| `app.js` | 탭 전환, 찜하기, 공유(링크 복사), 신청 모달·폼 검증·완료 화면 |
| `assets/` | 강사 사진, 교재 3D·평면 표지, 피클 아이콘 |

## 동작하는 기능

- 탭 전환: 소개 / 커리큘럼 / 강사 소개 / 질문 답변 (키보드 ←→ 지원, `#curriculum` 링크 지원)
- 찜하기 토글 (세션 동안 유지)
- 공유하기: Web Share API, 없으면 링크 복사 + 토스트
- 수강 신청: 모달 폼 검증 → 신청 번호가 있는 완료 화면 (입력값은 전송·저장되지 않음)

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 별도 빌드 과정 없는 정적 사이트입니다.
